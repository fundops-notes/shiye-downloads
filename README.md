# 拾页 · 桌面试用版下载

把文章、视频与播客整理为自己的收藏。文字与已归档图片保存在本机，使用自己的模型 API。

## 下载 0.9.0

[打开 Windows / Mac 下载页](https://github.com/fundops-notes/shiye-downloads/releases/tag/v0.9.0-trial)

- **Shiye-Windows-Trial.zip**：Windows 10/11 x64，自带 Python。
- **Shiye-Mac-Trial.zip**：目标 macOS 13+，含 Apple 芯片与 Intel 启动工具。已通过 GitHub macOS 原生启动检查；仍需朋友实机验证，未覆盖所有芯片及平台提取。
- **SHA256SUMS.txt**：安装包校验值。

无需 GitHub 仓库邀请即可下载。解压整个文件夹后，Windows 双击“启动拾页.cmd”，Mac 双击“启动拾页.command”。首次联网下载依赖，自动打开网页和邀请码文件。不是完全离线包，无需手动安装 Python。

## 0.9.0 更新

- 多家文字服务可以同时保存，一家可管理多个模型；可设置默认总结模型或为单次任务选择模型。
- 文字、语音、搜索配置独立，旧配置自动迁移。节点、密钥、模型变化后，相关测试记录失效。
- 文字/JSON、图片分开测试；语音使用固定短音频测试，实际结果可查看。云端测试可能计费。
- 原文和图片先存档，再总结。失败可复用原文，不重复下载和转写。
- 摘要重新生成或手动编辑保留历史，可预览、恢复。原文、个人笔记、自定义分类标签独立保存。完整备份包含摘要历史。
- 任务提交时记录配置快照。按原配置重试沿用原设置；要采用新设置，可在详情页选择模型重新总结。已经提交的任务不会因删除服务而撤销，需要时到处理中心取消。

## 数据与更新

更新前退出旧版并在网页做完整备份。解压新版启动即可沿用原数据目录：

- Windows：`%LOCALAPPDATA%/Shiye`
- Mac：`~/Library/Application Support/Shiye`

不要发送自己的数据库、API Key、credential.key 或资料目录给他人。API 费用以自己的服务商账单为准；软件不提供共享密钥或额度。

视频平台专用提取和本机 Whisper 提供按需安装入口；基础包没有本机文本模型、Whisper 权重和图片 OCR 引擎。选择“本机转写”只限制音频处理；文字总结是否联网由文字模型及搜索设置决定。
